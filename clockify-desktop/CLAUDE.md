# Project: Clockify Desktop Clone

## Tech Stack
- Runtime/Shell: Tauri v2 (Rust backend, React frontend)
- Frontend: React 19, TypeScript, Vite
- Styling: Tailwind CSS v3, shadcn/ui (Radix UI), Lucide React
- State Management: Zustand (`src/stores/useTimerStore.ts`)
- Date Utilities: date-fns

## Rules
- Strict focus: Only modify or create files explicitly requested. Do not scaffold unused features (e.g., do not build Reports, Timesheets, or Settings unless instructed).
- Maintain existing architecture in `src/`.
- Ensure all components are fully typed with TypeScript.
